### 20:45:30 — 방향별 배치 정리 (1.4.4 / 52)

### 23:04:25 — 간격 정돈과 재시작 편의 (1.5.2 / 56)

- 상황판·진행판의 제목 높이와 말·버튼 간격을 정돈했다. 화면 높이와 타이머 유무에 맞춰 간격을 조절하며 작은 화면의 4팀 표시가 잘리지 않도록 했다.

- 개발 현황·구조 설명·QA 체크리스트를 함께 갱신했다.
- 검증: 최종 단위·화면 테스트 122개, Android 에뮬레이터 테스트 35개 통과, lint 오류 0개, APK 빌드·내부 버전·서명 확인.

## 개발을 이어가기 전에

1. 이 문서를 먼저 읽고 `git status`로 기존 로컬 변경을 확인한다. 다른 사람이 남긴 변경이나 복구 자료를 지우지 않는다.
2. 현재 작업 브랜치는 `feat/team-piece-customization-1.4.0`이다. 브랜치 이름은 예전 버전이지만 최신 1.5.x 작업도 여기에 있다. `main`이 최신이라고 가정하지 않는다.
3. 원격 작업 브랜치를 fetch하고 로컬 HEAD와 비교한다. 로컬 변경이 있으면 보존한 뒤 진행하며 강제 푸시하지 않는다.
4. 실제 버전은 `app/build.gradle.kts`의 `versionName` / `versionCode`로 확인한다. 파일을 이름만 바꿔도 내부 버전은 바뀌지 않는다.
5. UI는 가로·세로, 시간 제한전·무제한전, 휴대폰·태블릿을 함께 확인한다. 이번 가로 변경을 세로에 적용하지 않는다.
6. 개발 후 이 문서의 최신 상태·검증 결과·남은 확인 항목도 함께 갱신한다. APK 전달과 GitHub 소스 반영을 모두 수행한다.

### 1.5.2에서 수정한 내용

- 가로 상황판·진행판의 제목 높이와 말·윷 버튼 간격을 정돈했다. 화면 높이에 따라 2/4/6dp 간격을 사용한다. 상황판은 타이머가 없는 무제한전에서 40/44dp, 시간전은 30/36dp 팀 행을 사용해 여유 공간에 맞춰 띄운다. 시간 변경 시에도 반영하며 작은 화면과 세로 화면의 표시를 보존한다.
- 게임 중 설정과 게임 규칙 창에서 제한 시간을 변경할 수 있다. 무제한으로 바꾸면 타이머를 끄고, 제한 시간으로 바꾸면 현재 팀에 선택한 시간을 새로 부여한다. 말 위치·현재 팀·미사용 윷 결과는 유지한다. 수동 정지 상태는 유지한다.
- 시간 기준이 달라지면 이전 시간 상태로 돌아가지 않도록 취소 기록을 비운다. 잡기 보너스 규칙은 게임 시작 전에만 바꾼다.
- 게임 화면의 기존 '새 게임' 버튼을 '다시하기'로 변경했다. 확인창은 '아니요 / 다시하기 / 새 게임' 세 선택지다. 초기화하는 두 선택지는 기존 3초 대기 후 활성화한다.
- '다시하기'는 팀 수·말 색·모양·잡기 규칙·제한 시간·피드백 설정을 유지하고 말 위치·턴·결과·기록·취소 이력을 초기화한다. '새 게임'은 팀 선택 화면으로 이동한다.
- 새 게임의 말 꾸미기에는 마지막으로 사용한 색·모양을 미리 채운다. 팀 선택 화면에서 종료 후 재실행해도 유지된다. 선택 창에서 취소한 초안은 마지막 실제 조합을 덮어쓰지 않는다.
- 기존 저장된 꾸미기 키를 사용하므로 저장 형식과 백업 형식은 변경하지 않았다.
