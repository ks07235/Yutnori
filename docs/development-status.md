# Yutnori 개발 현황과 인수인계

최종 갱신: 2026-09-27 (한국 시간)

## 개발을 이어가기 전에

1. 이 문서를 먼저 읽고 `git status`로 기존 로컬 변경을 확인한다. 다른 사람이 남긴 변경이나 복구 자료를 지우지 않는다.
2. 현재 작업 브랜치는 `feat/team-piece-customization-1.4.0`이다. 브랜치 이름은 예전 버전이지만 최신 1.5.x 작업도 여기에 있다. `main`이 최신이라고 가정하지 않는다.
3. 원격 작업 브랜치를 fetch하고 로컬 HEAD와 비교한다. 로컬 변경이 있으면 보존한 뒤 진행하며 강제 푸시하지 않는다.
4. 실제 버전은 `app/build.gradle.kts`의 `versionName` / `versionCode`로 확인한다. 파일을 이름만 바꿔도 내부 버전은 바뀌지 않는다.
5. UI는 가로·세로, 시간 제한전·무제한전, 휴대폰·태블릿을 함께 확인한다. 이번 가로 변경을 세로에 적용하지 않는다.
6. 개발 후 이 문서의 최신 상태·검증 결과·남은 확인 항목도 함께 갱신한다. APK 전달과 GitHub 소스 반영을 모두 수행한다.

### 1.5.1에서 수정한 내용

- 휴대폰 가로 화면 기본 위·아래 여백을 6dp에서 4dp로 축소했다.
- 가로 화면의 카메라 컷아웃 안전 영역과 좌우 제스처 영역은 유지한다.
- 위·아래의 강제 시스템 제스처 여백은 화면 전체에 적용하지 않고, 상태창의 버튼과 오른쪽 조작부에 분배한다. 윷판은 더 많은 높이를 사용한다.
- 오른쪽 `나온 윷 / 현재 팀 대기 말 / 윷 진행버튼`과 아래 취소·턴 종료·기록 버튼을 하나의 둥근 패널 배경으로 묶었다. 열 순서와 결과 스크롤은 유지한다.
- 패널 가장자리 간격을 확보한 만큼 진행버튼 열 폭을 6dp 줄여, 이전보다 판의 가용 폭이 줄지 않도록 했다.
- 세로 화면의 배치·안전 여백 계산은 그대로다. 시작 화면에서는 새 패널도 숨긴다.
- 게임 로직, 추가 기회 규칙, 저장 형식은 바꾸지 않았다.

### 이전 1.5.0 / build 54

기준 커밋: `c69e2eb9b6c8ae8fc08aa79c8f949830ca5c13b7`

- 팀별 색·모양이 각각 중복되지 않는 랜덤 추천.
- 가운데 흰색, 가운데·출발 이중 원.
- 윷·모 잡기 추가 기회는 기본 총 1회, 시작 전 스위치를 켜면 총 2회. 진행 중 규칙 변경 금지.
- 시간전 가로 타이머·정지 버튼을 왼쪽 상태창으로 이동.
- 가로 윷 입력은 도/윷, 개/모, 걸/빽도 순서. 아이콘 중앙 정렬과 빽도 검은 테두리.
- 취소는 실제 이동 역경로를 1.75배속으로 재생하고 연속 입력을 순차 처리. 회전 시 이미 복원한 게임 상태 보존.
- 애니메이션 줄이기, 실제 버전 복사, 이어하기 안내, 검증된 JSON 백업·복원.
- 자세한 내용은 [1.5.0 변경 내역](release-1.5.0.md)을 참조한다.

## 코드 탐색

- `MainActivity.java`: 방향별 배치, 안전 여백, 오른쪽 패널, 타이머·취소 애니메이션.
- `res/layout-land/activity_main.xml`: 가로 기본 배치. 세로는 `res/layout/activity_main.xml`.
- `YutGameEngine.java`: 이동·잡기·추가 기회. UI 변경 때문에 규칙을 변경하지 않는다.
- `GameStateStore.java`: 저장·취소 기록·백업과 구버전 상태 호환.
- `YutBoardView.java`, `BoardGeometry.java`, `BoardSurfaceLayout.java`: 판 그림과 좌표. 말 좌표와 그림을 따로 확대하지 않는다.
- `TeamAppearance.java`, `TeamAppearanceDialog.java`: 팀 꾸미기와 랜덤 추천.
- `YutDialogs.java`: 게임 규칙·설정·버전·백업 UI.

## 빌드·검증 방법

Android SDK 경로는 컴퓨터마다 설정한다. 이 컴퓨터는 `C:\Users\day07\AppData\Local\Android\Sdk`다.

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug --no-daemon --console plain
.\gradlew.bat connectedDebugAndroidTest --no-daemon --console plain
```

서명은 로컬 키 파일에 의존한다. `keystore.properties`와 키를 Git에 올리지 않는다. 디버그 APK는 스토어 배포용 서명 APK가 아니며, 다른 서명으로 설치된 앱 위에 업데이트되지 않을 수 있다. 기존 앱을 삭제해야 한다면 먼저 게임 백업을 확보한다.
