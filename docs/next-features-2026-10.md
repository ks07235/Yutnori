## 1. 잡기 연출 강화

구현: 약 600ms의 눌림·흔들림·포물선 복귀. 엔진 결과 확정 후 표시만 실행하며, 회전/백그라운드 취소 시 중복 처리하지 않는다. 기존 효과음·진동과 동작 줄이기 설정을 유지한다.

아래는 구현한 연출의 실기기 검수 기준이다. 말의 색·모양과 현재 판의 분위기를 유지하며, 효과가 겹쳐도 잡은 개수를 알아볼 수 있어야 한다. 연출 중에도 엔진의 이동·잡기 결과는 한 번만 확정하고 저장한다.

- 2개 이상 동시에 잡기, 업힌 말 잡기, 이동·잡기 중 화면 회전 또는 백그라운드 전환에서 잔상이나 중복 입력이 없어야 한다.
- 소리와 진동은 기존 설정을 따른다. 동작 줄이기를 켠 사용자에게는 긴 애니메이션 대신 짧은 상태 변화만 보여준다.
- 길이는 실제 기기에서 조절하되, 다음 턴 진행을 답답하게 만들지 않는 짧은 효과를 목표로 한다.

## 2. 승리 기록 화면

구현: 우승 팀부터 팀별 결과가 자동으로 올라가며, `건너뛰고 결과 보기` 또는 기록 터치로 정적 결과로 전환한다. 종료 후 직접 스크롤해서 다시 읽을 수 있다. 화면 회전/재실행 시에는 정적 결과로 복원한다. 잡은 말은 이벤트 횟수가 아닌 말 개수, 이동은 사용한 결과별 이동 구간 수다. 백도와 공동 최다 결과도 표시하며 옛 저장의 누락된 통계를 추정하지 않는다.

우승 직후 기록이 아래에서 위로 올라오는 짧은 엔딩 연출을 보여준다. 언제든 스킵할 수 있고, 스킵하면 통계가 한눈에 보이는 최종 결과 화면으로 즉시 이동한다. 연출이 끝나도 같은 결과 화면에 머물러 내용을 다시 읽을 수 있다.

- 첫 화면에는 우승 팀과 팀 색·말 모양을 크게 보여준다. 이어서 잡은 말 수, 도·개·걸·윷·모 횟수, 가장 많이 나온 윷 결과, 최대 업기 수, 이동 횟수처럼 실제로 수집한 기록만 표시한다.
- 단순 행동 로그 문자열을 해석해 통계를 추정하지 않는다. 게임 이벤트를 구조화해 기록하고, 취소·다시하기·저장·복원 후에도 숫자가 맞도록 한다. 수 읽기에서 발생한 가상 이동은 집계하지 않는다.
- 승리 연출 도중 회전·앱 종료·복귀·스킵을 해도 우승 결과가 중복 처리되거나 사라지지 않아야 한다. 동작 줄이기 설정에서는 스크롤 연출 없이 최종 결과를 바로 보여준다.

## 3. 수 읽기 모드

미구현 / 다음 우선순위. 이번 AAB에는 포함하지 않는다.

실제로 나온 윷 결과를 사용해 여러 수를 순서대로 시험하며, 말의 이동·업기·잡기·갈림길·완주를 판 위에서 비교한다. 예를 들어 윷·윷·개가 남았을 때 결과 선택 순서와 움직일 말을 바꾸어 볼 수 있어야 한다.

- 현재 게임 상태의 복사본에서만 계산한다. 시험 중 실제 말 위치, 남은 결과, 턴, 타이머, 취소 기록, 저장 게임과 통계는 변경하지 않는다.
- 이동 가능한 말과 도착 칸을 강조하고 시험 중인 말은 실제 말과 명확히 구분한다. 남은 윷과 사용한 수를 순서대로 보여준다.
- 한 수 되돌리기, 처음부터 다시 보기, 모드 닫기를 제공한다. 닫으면 원래 판으로 정확히 돌아온다.
- 터치로 말과 도착 칸을 고르는 조작을 먼저 구현한다. 드래그는 작은 칸·갈림길의 오입력을 실기기에서 확인한 후 보조 조작으로 추가한다. 드래그를 넣더라도 합법적인 도착 칸에만 붙인다.
- 이미 나온 결과만 시험한다. 이후 추가로 던질 윷의 결과는 예측하거나 만들어내지 않는다. 시간 제한전의 타이머는 수 읽기 중에도 기존 규칙대로 흐른다.
- 회전, 앱 백그라운드 전환, 시험 도중 시간 초과, 중복 탭을 검증한다. 시험을 끝냈을 때 실제 게임 상태가 모드 진입 전과 동일해야 한다.

## 작업 순서와 경계

구조 분리와 잡기·승리 기능의 자동 검증은 완료했다. 다음은 실제 기기에서 빌드 67을 검수하고 필요한 보완을 한 뒤 수 읽기 모드를 만드는 순서다. 실제 게임의 상태 확정·시간·취소·저장 순서를 유지하며, 수 읽기 단계에서는 시험판과 실제 판의 상태를 확실히 분리한다. 위의 수 읽기 세부사항은 제안 설계이며, 아직 구현하거나 검수한 동작이 아니다.

이전 로드맵의 실시간 판 공유, 선택형 로그인, 사진 말 꾸미기는 이번 우선순위에서 뒤로 둔다. 기능별 버전과 배포 시점은 구현·기기 검증 후 정한다.
