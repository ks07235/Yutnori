# Icon Usage

Yutnori uses in-house Android vector drawables for the action log rail and settings controls.

The current bundled log icons were created specifically for this app:

- `ic_log_move`
- `ic_log_capture`
- `ic_log_finish`
- `ic_log_yut`
- `ic_log_undo`
- `ic_log_turn_end`
- `ic_log_start`
- `ic_log_history`

Because these icons are project-owned assets rather than downloaded third-party icons, they can be used in commercial Play Store distribution with the app itself.

External icon libraries reviewed for future reference:

- Google Material Design Icons: Apache License 2.0
- Lucide: ISC License, with some Feather-derived MIT icons
- Remix Icon: commercial and non-commercial use allowed by its icon license, attribution optional

If any third-party icon is added later, keep the original license text or attribution note in this document before release.
