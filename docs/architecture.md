# Yutnori App Architecture

## 핵심 규칙

- `YutGameEngine.java`: 팀, 윷 결과, 선택 순서, 말 이동, 업기, 잡기, 완주, 턴 전환을 관리한다.
- `BoardPath.java`: 기본 경로, 지름길, 빽도와 이동 경로 추적을 담당한다.
- `Piece.java`: 말 하나의 위치, 경로와 완주 상태를 보관한다.
- 핵심 규칙은 Android UI에 의존하지 않으며 `YutGameEngineTest.java`로 검증한다.

## 화면 계층

- `MainActivity.java`: 화면 생명주기, 입력 연결, 타이머, 말 배치와 애니메이션을 조정한다.
- `YutDialogs.java`: 설정, 전체 기록, 게임 종료 다이얼로그를 만든다.
- `TeamAppearanceDialog.java`: 팀 수 선택 후 팀별 말 색과 모양을 고르는 팝업을 만든다. 게임 시작을 누르기 전까지는 초안만 변경한다.
- `TeamAppearance.java`: 저장 가능한 색·모양 ID, 추천 조합, 이전 저장 데이터 복원과 중복 색 검증을 담당한다.
- `PieceStackView.java`: 선택한 색과 모양으로 단독 말과 업힌 말을 함께 그린다. 밝은 말에는 어두운 숫자와 테두리를 사용한다.
- `YutBoardView.java`: 윷판을 그린다.
- `SquareFrameLayout.java`: 화면 비율과 무관하게 윷판을 정사각형으로 유지한다.
- `BoardGeometry.java`: 노드 좌표를 한 곳에서 관리한다.
- `BoardSurfaceLayout.java`: 판 그림과 말/화살표 계층에 동일한 정사각형 표시 영역을 부여한다.
- `BoardOverlayLayout.java`: 각 요소를 칸 번호에 연결하고 레이아웃마다 중심을 재계산한다.
- `BoardTouchTarget.java`: 작은 판에서 겹치는 터치 영역을 가까운 노드 기준으로 구분한다.

## 회전과 이동의 불변 조건

- 픽셀 좌표는 저장하지 않는다. 말의 논리 노드와 지름길 경로는 기존 엔진 상태를 유지한다.
- 이동 확정 시 엔진 결과, 다음 턴 시간, 잡기 보너스, 기록과 승리 안내 대기 상태를 먼저 반영하고 저장한다.
- 애니메이션은 표시만 담당한다. 회전, 크기 변경, 백그라운드 전환 시 중단하고 확정된 상태로 다시 그린다.
- 오래된 애니메이션의 콜백은 세대 번호로 무효화한다. 표시 취소가 게임을 다시 진행시키면 안 된다.
- 타이머 차감은 전경에서만 수행하며, 실행 중 시간 간격은 단조 증가 시계를 사용한다. 디스크에 저장한 시각으로 오프라인 시간을 차감하지 않는다.
- 승리 안내는 사용자가 확인하기 전까지 복원할 수 있게 저장한다.
- 입력 취소는 해당 결과에 부여한 시간도 취소한다. 제한 시간 변경 이전 결과에는 새 시간에서 보너스를 차감하지 않는다.

## 저장과 기기 기능

- `GameStateStore.java`: 설정, 게임 상태, 타이머 기준 시각과 최근 기록을 SharedPreferences에 저장한다.
- `GameFeedback.java`: 효과음과 진동을 담당한다.
- 저장 데이터는 복원 시 팀 수, 말 위치, 경로와 결과 ID를 검증한다.

## 반응형 레이아웃

- 게임 중 정보 패널은 항상 표시한다. 팀별 말 4개를 처음부터 채운 모양으로 보여주며, 완주한 말에만 X를 그린다.
- 입력 패널만 접을 수 있다. 세로 화면의 진행 표시는 2팀씩, 가로 화면은 1팀씩 배치한다.
- 화면 배치는 제한 시간 설정과 분리한다. 세로는 기존 시간제 형태의 하단 입력 패널을 사용하며, 게임 시작 시 열리고 사용자가 탭을 눌렀을 때만 접거나 펼친다. 이동·턴 전환으로 자동 전환하지 않으며 화면 재생성 시 선택을 유지한다. 무제한전의 시간 표시에는 '무제한'을 표시하고 시간 정지만 숨긴다.
- 가로는 왼쪽부터 상태창, 윷판, 나온 윷, 현재 팀의 대기 말 4개, 두 열의 윷 진행버튼을 고정 배치한다. 버튼은 도/윷, 개/모, 걸/빽도 순서다. 나온 윷은 독립된 세로 스크롤 영역이며, 취소·턴 종료·전체 기록은 오른쪽 아래에 둔다. 시간제의 시간 표시·정지는 제목·안내 상자를 없앤 왼쪽 상태창에 둔다. 상태창을 넓힌 만큼 오른쪽 폭을 줄여 1.4.4의 윷판 크기를 유지한다.
- 화면 회전 시 XML을 새로 만들고 현재 방향의 컨트롤을 연결한다. 제한 시간 변경만으로는 컨트롤을 이동시키지 않으며 게임 규칙과 저장 상태는 유지한다.
- 1.5.1 가로 화면은 오른쪽 세 열과 하단 작업 버튼 뒤에 `landscape_control_surface` 공통 패널을 둔다. 버튼과 결과 목록의 부모는 그대로여서 스크롤·터치·좌표 계산은 기존 구조를 사용한다. 시작 화면에서는 배경도 숨긴다.
- 가로 안전 여백은 카메라 컷아웃과 좌우 제스처를 보존한다. 위·아래 제스처 여백은 루트에 최대 4dp만 적용하고, 남은 보호 공간을 왼쪽 상태창과 오른쪽 조작부에 적용한다. 세로의 전체 안전 여백 방식은 유지한다. 휴대폰 가로 기본 수직 간격은 4dp다.
- 앱은 밝은 배경용 글자색에 맞춰 Light 테마를 사용하고 강제 다크 변환을 끈다. 기기 다크 모드에서도 설정 및 다른 다이얼로그의 대비를 유지한다.
- 새 게임 확인 버튼은 3초 후 활성화되며, 사용자가 직접 확인해야 시작한다. 창을 닫으면 카운트다운을 취소한다.
- 새 게임의 윷·모 잡기는 추가 기회 총 1회가 기본이다. 시작 전 규칙의 중복 허용 스위치를 켜면 잡기 보너스도 추가한다. 복합 이동은 각 결과의 잡기 착지를 기준으로 계산하며, 진행 중 규칙과 제한 시간은 설정 UI에서 바꿀 수 없다. 기존 저장 게임은 이전의 중복 허용 규칙을 유지한다.
- 취소 시 엔진과 저장은 먼저 복원하고, 보관한 역경로를 약 1.75배 속도의 루트 오버레이로 표시한다. 연속 취소는 대기열을 순서대로 소비한다. 회전·백그라운드 전환은 표시와 아직 실행하지 않은 요청만 정리한다. 애니메이션 줄이기는 이동·취소 여행과 안내 펄스를 생략한다.
- 추천 조합은 색과 모양을 각각 비복원 추출하며, 참여 팀 전체의 직전 조합과 같은 추천은 피한다. 수동 색·모양 선택은 기존 동작을 유지한다.
- 설정에서 버전을 복사하고 Storage Access Framework로 JSON 게임 백업을 내보내거나 가져온다. 규칙·말 꾸미기·선택·취소 역경로를 포함한다. 가져오기는 확인 후 크기·형식·타입·말 배열을 검증하고, 복원된 시간은 일시 정지한다. 백업은 서버에 자동 전송하지 않는다.
- 말 지름은 휴대폰 36dp, 태블릿 44dp로 유지한다. 테두리는 말과 같은 색을 사용하되 흰 말은 검은 테두리로 구분한다.
- 취소 기록은 윷 입력·말 이동·수동 턴 종료 전의 엔진, 시간, 선택, 기록 상태를 최근 100개까지 연결해 저장한다. 취소할 때 마지막 상태를 꺼내며, 재실행 후에도 남은 기록을 복원한다. 새 게임·시간 제한 변경·시간 초과 턴 전환은 기존 취소 기록을 초기화한다. 이전 버전의 단일 이동 취소 상태도 가져온다.
- 엔진의 이동 미리보기가 완주를 반환하면 윷판 밖에 임시 골인 칸을 표시한다. 골인 칸은 클릭 시에도 미리보기를 다시 확인하고 기존 이동 확정 흐름을 사용한다. 게임 경로와 완주 규칙은 변경하지 않는다.
- `BoardUxTest`는 Robolectric으로 작은 세로·가로 화면의 팀 표시와 실제 터치 이벤트를 통한 업힌 말 완주를 검증한다.
- 완주 애니메이션은 마지막 보드 노드까지 기존 경로 이동을 실행한 뒤, 루트 오버레이의 말이 골인 칸까지 이동하고 사라진다. 이때 골인 칸은 유지하여 보드 재배치가 애니메이션을 취소하지 않도록 한다. 회전·백그라운드 전환으로 취소하면 오버레이를 정리하고 이미 확정한 엔진 상태를 다시 표시한다.
- `res/layout`: 휴대폰 세로
- `res/layout-land`: 휴대폰 가로와 접이식 좁은 가로
- `res/layout-sw600dp`: 태블릿 세로
- `res/layout-sw600dp-land`: 태블릿 가로
