# Yutnori QA Checklist

## 저장과 복원

- 게임 중 앱을 백그라운드로 보낸 뒤 돌아와도 팀, 말, 결과 선택 순서가 유지된다.
- 앱 프로세스를 종료한 뒤 다시 실행해도 마지막 게임이 복원된다.
- 앱을 백그라운드로 보내면 타이머가 자동으로 멈추고 돌아오면 이어서 진행한다.
- 수동으로 정지한 타이머는 앱에 돌아와도 정지 상태를 유지한다.
- 효과음, 진동, 제한 시간 설정과 최근 기록이 유지된다.

## 화면과 조작

- 정보 패널은 입력 패널을 접거나 말을 선택해도 항상 보이며, 모든 팀의 말 4개가 표시된다.
- 모든 팀의 말 4개가 처음부터 채워져 있고, 완주한 말에만 X가 표시된다. 완주를 취소하면 X가 사라진다.
- 완주 가능한 결과와 말을 선택했을 때만 윷판 오른쪽 아래 바깥에 골인 칸이 나타난다.
- 도착 노드의 말과 골인 칸의 터치 영역이 겹치지 않으며, 골인 칸을 누르면 업힌 말도 함께 완주한다.
- 도착 노드에 단순히 착지하거나 빽도를 선택하면 골인 칸이 나타나지 않는다.
- 입력 취소와 말 선택 해제 후 골인 칸이 사라진다.
- 말은 경로를 따라 출발/도착 노드까지 이동한 뒤 별도 골인 칸으로 넘어가며 사라진다. 업힌 말도 같은 흐름으로 완주한다.
- 골인 애니메이션 중 회전하거나 화면을 재생성해도 완주 상태와 진행 표시가 유지되고 잔상이 남지 않는다.
- 세로는 시간제·무제한전 모두 기존 시간제 형태의 하단 입력 패널을 사용한다. 처음에 열려 있고, 말 선택·이동·턴 전환 후에도 사용자가 정한 열림 상태를 유지한다.
- 가로는 시간제·무제한전 모두 상태창 → 윷판 → 세로 나온 윷 → 세로 대기 말 → 두 열 윷 진행버튼 순서다. 입력 패널·접기 탭은 보이지 않고 취소·턴 종료·기록은 오른쪽 아래에 유지된다.
- 나온 윷이 많으면 그 영역만 세로 스크롤할 수 있으며 마지막 결과도 선택할 수 있다. 대기 말과 윷 진행버튼을 가리지 않는다.
- 시간제의 시간 표시와 정지 버튼은 가로에서 왼쪽 상태창에 보인다. 가로의 제목·안내 상자는 없고 윷판 크기는 유지된다. 세로 무제한전에는 '무제한' 표시만 보이며 시간 정지는 숨겨진다.
- 가로 버튼은 도/윷, 개/모, 걸/빽도 순서이고, 빽도에 검은 테두리가 있다. 네 칸 그림은 가운데 정렬되며 윷판 중앙은 흰색, 중앙과 출발은 이중 원이다.
- 이동 취소는 역경로로 빠르게 복귀하고 연속 취소 요청은 순서대로 완료된다. 취소 중 회전·백그라운드 전환·재실행에도 복원한 엔진 상태가 유지된다.
- 애니메이션 줄이기를 적용하면 이동·취소 모션을 생략해도 최종 말 위치와 규칙은 같다.
- 추천 조합을 반복 누르면 참여 팀의 색과 모양이 각각 겹치지 않고 전체 직전 조합과 다르게 바뀐다.
- 시작 전 중복 허용 OFF/ON에서 윷·모 잡기 추가 기회가 각각 총 1회/2회다. 미리 추가 기회를 사용한 뒤 잡거나 여러 결과로 잡아도 이중으로 계산하지 않는다.
- 게임 중에는 규칙·제한 시간을 수정할 수 없으며, 추가 던지기 횟수와 취소 대상이 안내된다.
- 저장 파일의 규칙·말 꾸미기·선택·취소 기록이 복원되고 타이머가 일시 정지한다. 잘못된 파일은 현재 게임을 바꾸지 않는다.
- 설정의 버전 정보를 누르면 실제 버전·빌드 번호가 복사된다.
- 무제한전과 시간제를 반복 전환하고 새 게임을 시작해도 버튼이 사라지거나 중복되지 않는다.
- 화면을 반복 회전해도 말의 지름이 유지되며, 테두리가 말과 같은 색으로 보인다. 흰 말은 예외로 검은 테두리를 사용한다.
- 모든 가로 화면에서는 대기 말이 윷 진행버튼 왼쪽에 세로로 배열되고 네 번째 말까지 온전히 보인다.
- 기기를 다크 모드로 설정해도 설정창의 배경은 밝고 글자와 선택지가 선명하게 보인다.
- 새 게임 확인 버튼은 3초 전까지 비활성화되고 3초 후 활성화된다. 자동으로 게임을 시작하지 않으며, 기다리는 중 취소하면 기존 게임이 유지된다.
- 윷 입력·말 이동·수동 턴 종료를 연속으로 취소하면 역순으로 되돌아가며, 재실행 후에도 이전 취소가 이어진다.
- 새 게임이나 시간 제한 변경 후에는 이전 게임의 취소 기록을 사용할 수 없다.
- 휴대폰 세로와 가로에서 윷판과 조작 패널이 겹치지 않는다.
- 이동 애니메이션 중 회전해도 말이 최종 위치에 정확히 표시된다.
- 회전을 반복해도 판 그림, 말, 도착 화살표의 중심과 실제 터치 판정이 일치한다.
- 이동 중 회전으로 다음 팀의 시간이 이전 팀의 시간으로 되돌아가지 않는다.
- 잡기 중 회전해도 추가 입력 횟수와 시간 보너스가 누락되거나 중복되지 않는다.
- 마지막 말 완주 중 회전하거나 화면을 재생성해도 승리 안내가 나타난다.
- 백그라운드에서 저장 함수가 다시 실행돼도 시간이 차감되지 않는다.
- 태블릿 가로에서 네 번째 대기 말의 터치 영역 전체가 대기 영역 안에 들어간다.
- 태블릿 세로와 가로에서 정보, 윷판, 조작 패널이 모두 보인다.
- 시스템 내비게이션 방식과 글자 크기를 바꿔도 핵심 버튼이 잘리지 않는다.

## 게임 흐름

- 2팀, 3팀, 4팀을 선택한 수만큼만 게임에 참여한다.
- 팀 수를 누르면 말 꾸미기 팝업이 열리고, 게임 시작을 누른 뒤에만 선택한 수의 팀이 배치된다.
- 돌아가기와 시스템 뒤로 가기는 게임을 시작하지 않고 팀 수 선택 화면으로 돌아온다.
- 추천 조합은 개나리색을 포함하며, 개나리·흰색·검정 등 10가지 색과 6가지 모양을 선택할 수 있다.
- 다른 팀이 사용하는 색은 선택되지 않으며 사용 중인 팀을 안내한다. 추천 조합 버튼은 선택 초안을 초기화한다.
- 흰색과 개나리색의 숫자 및 테두리가 밝은 윷판에서도 보이고, 검정색의 숫자가 선명하게 보인다.
- 말 꾸미기 팝업의 초안은 화면 재생성 시 유지되고, 게임 시작 후 색과 모양은 앱 재실행·회전·업기·잡기·완주 후에도 유지된다.
- 이전 버전 저장 게임은 기존 빨강·파랑·보라·초록의 원형 말로 복원된다.
- 작은 휴대폰 가로 화면과 큰 글자 설정에서도 팝업을 스크롤해 모든 선택지와 시작·추천·돌아가기 버튼을 사용할 수 있다.
- 여러 윷 결과를 원하는 순서로 선택하고 한 말에 연속 적용할 수 있다.
- 선택한 말의 도착 미리보기와 화살표 이동이 동일한 결과를 낸다.
- 윷, 모, 잡기 후 추가 입력과 수동 턴 종료가 정상 동작한다.
- 윷 또는 모를 입력한 뒤 취소하면 30초 보너스도 함께 취소된다.
- 한 번에 선택한 여러 결과로 서로 다른 칸에서 두 번 잡으면 추가 기회도 두 번이다. 한 칸의 업힌 말은 한 번으로 센다.
- 일부 결과만 사용하고 남은 결과가 있어도 조작 패널의 열림 상태는 바뀌지 않는다.
- 기록은 최근 200개까지 보관하며 출발/도착 위치를 표시한다.
- 업기, 잡기, 빽도, 지름길, 완주와 승리 판정이 정상 동작한다.
- 승리 후 입력은 막히고 종료 다이얼로그가 표시된다.

## 출시 전 자동 검증

- 가로 화면의 오른쪽 세 열과 취소·턴 종료가 하나의 공통 패널 안에 표시되고, 게임 시작 전에는 패널이 숨겨진다.
- 가로에서 위·아래 여백을 줄여도 카메라 컷아웃과 홈 제스처 영역의 버튼 보호는 유지된다. 같은 Insets가 반복 전달되어도 여백이 누적되지 않는다.
- 가로에서 세로로 회전하면 원래 세로 배치와 전체 안전 여백으로 복귀하고 게임 상태가 유지된다.

- `gradlew testDebugUnitTest`가 통과한다.
- `gradlew lintDebug`가 오류 없이 통과한다.
- `gradlew assembleDebug`가 통과한다.
- 실제 API 24 기기 또는 에뮬레이터와 최신 Android 기기에서 핵심 흐름을 확인한다.
