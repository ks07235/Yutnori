# Yutnori 1.5.0 (build 54)

## 게임 규칙

- 새 게임은 윷·모로 잡았을 때 추가 기회 총 1회가 기본이다.
- 시작 전 게임 규칙의 '윷·모 잡기 보너스 중복 허용'을 켜면 추가 기회 총 2회다.
- 복합 이동은 잡기가 발생한 결과별로 계산하고, 이미 사용한 윷·모 보너스를 다시 주지 않는다.
- 진행 중 규칙과 제한 시간은 고정한다. 기존 저장 게임은 이전 규칙을 유지한다.

## 화면과 조작

- 가로 시간전의 제목과 안내 상자를 없애고, 왼쪽 상태창에 시간·정지 버튼을 배치한다.
- 상태창을 넓힌 만큼 오른쪽 폭을 줄여 이전 윷판 크기를 유지한다.
- 가로 진행버튼은 도/윷, 개/모, 걸/빽도 순서다. 네 칸 그림을 가운데 정렬하고 빽도에는 검은 테두리를 적용한다.
- 중앙은 흰색으로, 중앙과 출발은 이중 원으로 그린다.
- 추가 던지기 횟수를 표시하고, 취소 버튼을 길게 누르면 취소 대상을 안내한다.
- 이동 취소는 역경로를 1.75배 속도로 복귀한다. 연속 취소는 한 단계씩 재생하고 이동 없는 취소는 바로 처리한다.
- 회전·백그라운드 전환 시 이미 복원한 상태를 유지하고 모션·아직 실행하지 않은 대기 요청을 정리한다.

## 꾸미기와 저장

- 추천 조합은 참여 팀의 색과 모양이 각각 겹치지 않는 랜덤이다. 전체 직전 추천과 같은 조합은 피한다.
- 설정의 '애니메이션 줄이기'는 말 이동·취소 모션과 안내 펄스를 생략한다.
- 설정에서 실제 버전을 눌러 복사할 수 있다.
- 이어하기 시 팀 수·현재 팀·남은 결과를 안내한다.
- 설정에서 JSON 게임 저장 파일을 내보내거나 가져올 수 있다. 규칙·말 꾸미기·선택·취소 기록과 역경로를 포함한다.
- 가져오기는 교체 확인 후 유효성을 검사하고, 실패하면 기존 게임을 유지한다. 복원한 타이머는 일시 정지한다.
